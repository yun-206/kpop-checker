K-pop 해외공연 데이터 도구

원본 데이터로 결과 엑셀을 만들고(순위 자동 산정), 규칙 위반을 검사해요. 파일은 이 브라우저 안에서만 처리되고 어디에도 전송되지 않아요.

원본 데이터 → 결과 엑셀
  1. 원본 데이터 파일을 올려요. 새 공연이 있으면 업데이트 파일도 같이 올려요(합쳐서 계산).
  2. 자동 순위 연도는 공식 관객수 → (없으면) 수용인원×일수로 합산하고, 공식누적 시트의 묶음은 공식 합계를 한 번만 더해요.
  3. 결과 엑셀은 박사님 양식(두 시트·목록·변수 설명)으로 나오고, 만들자마자 ② 검증을 자동으로 돌려요.

기존 결과 엑셀 → 원본 데이터 파일
  1. 지금까지 쓰던 엑셀(해외 공연 현황 시트가 있는 파일)을 올리면 원본 데이터 파일로 바꿔줘요.
  2. [예정] 태그는 떼고, attendance의 "(소속사 제공)" 같은 표시는 attendance_label 열로 옮겨요. 원자료에서 attendance가 수식(수용인원×일수)이던 행은 attendance_rule 열에 표시해요.
  3. 공연장마스터는 기존 기입값으로 초안만 만들어요. source(출처)를 적은 공연장만 빈 capacity를 채우는 데 쓰여요.
  4. 공식누적 시트에 공식 합계(예: 돔 4회 합계 17만 명)를 적고, 공연목록의 집계묶음 열에 같은 이름을 적으면 순위 산정에 반영돼요.
