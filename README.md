# K-pop 해외공연 데이터 검증기

엑셀 데이터셋(`해외 공연 현황` / `해외 공연 현황 (2)` / `연도별 아티스트 목록`)을 올리면 규칙 위반을 찾아주는 웹페이지입니다.
**파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.**

## 배포 (GitHub Pages, 무료)

1. GitHub에서 새 저장소 만들기 (예: `kpop-checker`, **Public**)
2. 이 폴더의 파일을 그대로 업로드 → `Add file` → `Upload files`
   - `index.html`, `checker.js`, `README.md`, `.gitignore`
3. 저장소 `Settings` → `Pages` → Source: `Deploy from a branch` → Branch: `main` / `(root)` → `Save`
4. 1~2분 뒤 `https://<아이디>.github.io/kpop-checker/` 에서 열림

> ⚠ 데이터 엑셀은 저장소에 절대 올리지 마세요. 저장소는 공개이고, 코드만 올라가야 합니다. `.gitignore`가 `*.xlsx`를 막아둡니다.

## 사용법

1. ① 데이터셋 엑셀을 끌어다 놓기
2. (선택) ② 공연장 마스터 엑셀 — 열 이름 `location`, `city`, `capacity`, `source`
3. 기준일(오늘) 확인 → `검사 실행`
4. 등급·검사 항목·연도·검색으로 걸러 보고, `오류 리포트 .xlsx`로 내려받기
5. `공연장 마스터 초안`을 내려받아 capacity·source를 공식 수치로 채우면, 다음 검사부터 ②에 넣어 대조할 수 있음

## 검사 항목

| 등급 | 항목 |
|---|---|
| 오류 | 국내(한국) 공연 포함, 관객수 > 수용인원, 중복 행, 그룹 블록 끊김, 순위와 블록 순서 불일치(엄격 연도), 두 시트 값 불일치, 수식이 다른 행 참조, no 연번, 분기(qt), 날짜·일수 모순 |
| 확인필요 | capacity에 여러 날 합계 의심, 관객수=수용인원×일수(복사 의심), 같은 공연장 capacity 불일치, 공연장 마스터와 불일치, 블록 안 날짜순, 목록 밖(16위 이하) 상세 행, capacity 숫자 아님, [예정]/[일부 예정] 표시 누락 |
| 참고 | 이미 끝난 [예정] 공연, 마스터로 채울 수 있는 빈 capacity, 엄격 연도 이전 데이터의 복사 의심 |

'엄격 검사 시작 연도'(기본 2025) 이전 데이터는 일부 항목을 '참고'로 낮춰 보여줍니다.

## 파일 구성

- `index.html` — 화면
- `checker.js` — 검사 규칙 (규칙 추가는 여기서)
- SheetJS(xlsx 0.18.5)를 cdnjs에서 불러옵니다.
