# K-pop 해외공연 데이터 도구

원본 데이터로 박사님 양식의 결과 엑셀을 만들고(순위 자동 산정), 규칙 위반을 검사하는 웹페이지입니다.
**파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.**

## 탭 구성

| 탭 | 하는 일 |
|---|---|
| ① 조립·순위 | 원본 데이터(+업데이트 파일) → 결과 엑셀(해외 공연 현황 / (2) / 연도별 아티스트 목록 / 변수 설명). 자동 순위 연도는 순위를 다시 계산해 상위 N팀만 상세 수록, [예정]·[일부 예정] 태그와 색칠, 수식(qt·capacity*days) 자동. 만들자마자 ② 검증 실행 |
| ② 검증 | 결과 엑셀의 규칙 위반 검사 (21개 데이터 품질 규칙) |
| ③ 원본 변환 | 기존 결과 엑셀 → 원본 데이터 파일 (처음 1회) |

## 원본 데이터 파일 구조

| 시트 | 내용 |
|---|---|
| 공연목록 | 공연 1행 = 1줄. `attendance_label`(예: 소속사 제공)은 숫자 서식 괄호로 출력. `attendance_rule`은 원자료에서 attendance가 수용인원×일수 수식이던 행 표시. `집계묶음`은 공식누적과 연결 |
| 솔로부록 | 본문 뒤에 붙는 솔로 공연(순서 그대로) |
| 공연장마스터 | location·city·capacity·source. **source를 적은 공연장만** 빈 capacity를 채우는 데 쓰임 |
| 공식누적 | 공연장별 수치는 없고 합계만 공식 발표된 경우(예: 돔 4회 합계 17만). 순위 산정 때 묶음 합계를 한 번만 더함 |
| 연도별목록 / 변수설명 | 결과 엑셀에 그대로 들어감(자동 순위 연도 행만 다시 씀) |
| 설정 | 기준일, 자동순위연도, 상위N |

## 업데이트 파일

'업데이트' 시트 한 행 = 작업 하나. `작업` 열에 추가 / 수정 / 삭제.
- 추가: 새 공연. gender~agency3가 비면 같은 아티스트 기존 행에서 복사
- 수정: `대상_start_date`·`대상_location`으로 기존 공연을 찾아 값을 적은 칸만 바꿈. `(비움)`은 칸 비우기, `+ 내용`은 기존 글 뒤에 덧붙이기
- 삭제: 대상 공연 삭제
- '공식누적' 시트: 같은 집계묶음이면 덮어쓰기

①에서 원본 + 업데이트를 같이 올리면 변경 내역표가 나오고, `새 원본 받기`로 합쳐진 최신 원본을 받아 다음 업데이트에 씀.

## 순위 산정 규칙

1. 공식누적 묶음 → 공식 합계
2. 그 외 행 → attendance(공식 관객수), 없으면 capacity × days
3. 수치가 둘 다 없는 행은 0으로 계산되고 화면에 '수치 없는 행'으로 표시
